# سئوکاو

داشبورد رایگان و فارسی برای بررسی ساختار ووکامرس و مدیریت چند سایت از داخل مرورگر.

## امکانات نسخهٔ عمومی

- ثبت و مدیریت چند سایت
- دریافت عمومی دسته‌بندی‌ها و محصولات منتشرشدهٔ ووکامرس
- شش نمای درختی، نمای کلی گرافی، شاخه‌ای تعاملی، نقشه‌ای، ستونی و کارتی
- نمای کامل ساختار با اتصال والد و فرزند، زوم، جابه‌جایی، مینی‌مپ و فیلتر شاخه
- نمایش قرمز دسته‌بندی‌های بدون محصول در نمای کلی
- انتخاب شاخهٔ اصلی و باز و بسته‌کردن مرحله‌ای زیرشاخه‌ها
- ممیزی دسته‌های خالی، عمق ساختار و نامک‌های تکراری
- مدیریت محلی کارهای سئو
- تقویم روزانهٔ کارها با تاریخ، ساعت، نوع کار، زمان برآوردی و زمان تکمیل
- گزارش عملکرد ماهانه و خروجی CSV و JSON از کارهای انجام‌شده و باز
- تم روشن و تاریک سراسری با ذخیرهٔ انتخاب کاربر
- خروجی JSON و CSV و پشتیبان کامل
- اتصال امن افزونه برای دریافت همهٔ وضعیت‌های محصول و فعال‌کردن ویرایش
- فیلتر محصولات منتشرشده، پیش‌نویس، در انتظار، خصوصی، زمان‌بندی‌شده و زباله‌دان
- ویرایش نام، نامک، وضعیت، SKU، قیمت، موجودی، دسته، محتوا و متادیتای سئوی محصول
- ویرایش نام، نامک، والد، توضیحات و متادیتای سئوی دسته‌بندی

## حریم خصوصی

این مخزن هیچ داده، دامنه، حساب، رمز یا کلید API پیش‌فرضی ندارد. داده‌هایی که کاربر وارد می‌کند فقط در `localStorage` مرورگر خودش ذخیره می‌شوند.

دسته‌ها و محصولات منتشرشده بلافاصله بعد از ثبت دامنه و بدون افزونه دریافت می‌شوند. هنگام اولین تلاش برای ویرایش دسته یا محصول، برنامه راهنمای نصب افزونهٔ نسخهٔ ۱.۱ را نشان می‌دهد. کلید ساخته‌شده در «ابزارها ← اتصال سئوکاو» فقط در مرورگر کاربر ذخیره می‌شود.
