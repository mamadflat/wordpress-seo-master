# سئوکاو

داشبورد رایگان و فارسی برای بررسی ساختار ووکامرس و مدیریت چند سایت از داخل مرورگر.

## امکانات نسخهٔ عمومی

- ثبت و مدیریت چند سایت
- دریافت عمومی دسته‌بندی‌ها و محصولات منتشرشدهٔ ووکامرس
- پنج نمای درختی، شاخه‌ای، نقشه‌ای، ستونی و کارتی
- ممیزی دسته‌های خالی، عمق ساختار و نامک‌های تکراری
- مدیریت محلی کارهای سئو
- خروجی JSON و CSV و پشتیبان کامل
- اتصال امن افزونه برای دریافت همهٔ وضعیت‌های محصول
- فیلتر محصولات منتشرشده، پیش‌نویس، در انتظار، خصوصی، زمان‌بندی‌شده و زباله‌دان
- ویرایش نام، نامک، وضعیت، SKU، قیمت، موجودی، دسته، محتوا و متادیتای سئوی محصول

## حریم خصوصی

این مخزن هیچ داده، دامنه، حساب، رمز یا کلید API پیش‌فرضی ندارد. داده‌هایی که کاربر وارد می‌کند فقط در `localStorage` مرورگر خودش ذخیره می‌شوند.

برای ویرایش محصولات، افزونهٔ نسخهٔ ۱.۱ را نصب کنید و کلید ساخته‌شده در «ابزارها ← اتصال سئوکاو» را داخل تنظیمات همان سایت در داشبورد قرار دهید. کلید فقط در مرورگر کاربر ذخیره می‌شود.
