# درخت‌یار وردپرس

ابزار رایگان و فارسی برای نمایش، جست‌وجو، بررسی و خروجی‌گیری از ساختار دسته‌بندی‌های وردپرس و ووکامرس.

## امکانات

- ورود فایل JSON و CSV
- نمایش درخت تعاملی دسته‌ها
- جست‌وجوی نام و نامک
- نمایش دسته‌های خالی و عمق ساختار
- خروجی JSON، CSV، SVG و PDF
- اجرای کامل در مرورگر بدون ارسال اطلاعات فروشگاه به سرور

نسخه اولیه شامل ساختار واقعی دسته‌بندی‌های یدک همراه است.
