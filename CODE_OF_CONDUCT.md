# Code of Conduct

## Our Standard

Project participants are expected to communicate respectfully, provide actionable
feedback, welcome different levels of experience, and keep technical discussion
focused on improving the project.

Harassment, discrimination, personal attacks, publication of private information,
and deliberately disruptive behavior are not acceptable.

## Scope

This standard applies to repository issues, pull requests, discussions, reviews,
and other spaces where a participant represents the project.

## Enforcement

Report unacceptable behavior privately through the repository maintainers or the
appropriate GitHub reporting tools. Maintainers may edit or remove content and may
temporarily or permanently restrict participation when necessary.
