# Seokav 1.2.0

Seokav 1.2.0 turns the original taxonomy viewer into a more complete,
privacy-first SEO operations dashboard for multiple WordPress and WooCommerce
sites.

## Highlights

- Explore complete category relationships in an interactive graph with zoom,
  pan, fit-to-screen, root filtering, a minimap, and red empty-category nodes.
- Switch between light and dark themes across all eight dashboard pages.
- Load public categories and products before installing the connector, then
  unlock authenticated editing and private product statuses when ready.
- Review published, draft, pending, private, and trashed WooCommerce products.
- Create, schedule, complete, filter, and review SEO tasks by day and month.
- Export monthly task activity as CSV or JSON for client and team reporting.
- Manage several websites from one local-first workspace without a central
  Seokav backend.

## Documentation and Engineering

- Added complete English product, user, development, architecture, connector,
  security, contribution, and release documentation.
- Added reproducible connector build scripts for Windows, macOS, and Linux.
- Added automated validation for application syntax, version consistency,
  WordPress connector syntax, and connector archive parity.
- Added GitHub issue forms, a pull request template, and repository governance
  documents.

## Upgrade Notes

The dashboard stores browser data under the existing
`seokav.public.dashboard.v2` local-storage key, so an upgrade from 1.1 does not
require migration. The bundled WordPress connector remains version 1.1.0.

Download `seokav-connector.zip` from this release if the connector is not
already installed. Existing connector users do not need to reinstall it for
the dashboard-only 1.2.0 features.
