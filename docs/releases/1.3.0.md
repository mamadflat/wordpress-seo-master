# Seokav 1.3.0

Seokav 1.3.0 adds an optional Team mode for shared site-level access.

## Highlights

- Create a Workspace and invite separate user accounts.
- Add multiple WordPress sites to one Workspace.
- Assign each member `viewer`, `editor`, or `manager` access per site.
- Enforce site membership on the API, not only in the browser interface.
- Encrypt connector keys with AES-256-GCM and keep them out of member browsers.
- Proxy authorized WordPress requests and record mutation audit entries.

## Important deployment note

The public GitHub Pages frontend remains usable in local-first mode. Team mode
requires a separately deployed Node API, PostgreSQL, HTTPS, a strong encryption
key, and `config.js` pointing to the API. Do not put database credentials or
`SEOKAV_ENCRYPTION_KEY` in GitHub Pages or frontend code.
