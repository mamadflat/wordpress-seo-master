# Seokav 1.2.1

Seokav 1.2.1 is a release-readiness patch for the local-first SEO dashboard and its WordPress connector.

## Highlights

- Corrected repository, deployment, release, and issue-reporting links so they point to `mamadflat/wordpress-seo-master`.
- Hardened the connector's authenticated content route to accept only posts and pages with supported WordPress statuses.
- Fixed category fallback behavior so category operations use the active WordPress taxonomy when WooCommerce is unavailable.
- Rebuilt `seokav-connector.zip` from the reviewed connector source.

## Upgrade Notes

The dashboard continues to use the existing `seokav.public.dashboard.v2` local-storage key. The bundled WordPress connector is now version 1.1.1. Existing connector users may continue using 1.1.0, but should install 1.1.1 to receive the taxonomy and content-route fixes.

## Verification

The static validation suite, browser smoke tests, connector archive parity check, and GitHub Actions workflow are part of the release checklist. The release archive must be rebuilt with `npm run build:connector` after connector source changes.
